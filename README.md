## 🚀 Featured RTL Projects

### 1. 🔢 4-Bit ALU Design Using Verilog
Designed a 4-bit Arithmetic Logic Unit to perform basic arithmetic and logical operations. Verified its behavior through simulation and waveform analysis.

🔗 [View Repository](https://github.com/krushnapatil1/4-bit-ALU-Project)

### 2. 📡 UART Protocol Using Verilog
Implemented UART transmitter and receiver modules using finite state machines. Developed testbenches to verify serial data transmission and reception.

🔗 [View Repository](https://github.com/krushnapatil1/UART-Protocol-Using-Verilog)

### 3. 🔌 SPI Protocol Using Verilog
Designed and simulated an SPI Mode 0 communication interface with serial data transmission, reception, and control logic.

🔗 [View Repository](https://github.com/krushnapatil1/SPI-Protocol-Using-Verilog)

### 4. 📥 Synchronous FIFO Design and Verification
Designed an 8-bit-wide, depth-8 synchronous FIFO with read/write pointers, occupancy tracking, and full/empty status flags. Verified FIFO behavior using a Verilog testbench.

🔗 [View Repository](https://github.com/krushnapatil1/Synchronous-FIFO-Design-and-Verify-using-Verilog)

### 5. 🔄 Asynchronous FIFO Design and Verification
Working with dual-clock FIFO architecture, binary and Gray code pointers, and pointer synchronization between independent clock domains.

🔗 [View Repository](https://github.com/krushnapatil1/Asynchronous-FIFO-design-and-Verification-using-Verilog)
